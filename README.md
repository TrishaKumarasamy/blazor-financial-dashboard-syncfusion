# Simple Financial Dashboard

A comprehensive financial analytics dashboard built with Blazor Server and Components, featuring interactive pivot tables, charts, and data grids for powerful financial data visualization and analysis.

## Overview

This application provides real-time financial data analysis with:

- **Interactive Pivot Table** with drag-and-drop field analysis
- **Summary Cards** displaying key financial metrics
- **Regional & Departmental Charts** for performance visualization
- **Advanced Data Grid** with filtering, sorting, and export capabilities
- **Budget Variance Tracking** with color-coded indicators

## Features

### Data Analysis
- Multi-dimensional analysis by Department, Category, Region, Year, and Quarter
- Dynamic filtering with Status, Priority, and custom dimensions
- Budget variance calculations with real-time tracking
- Transaction categorization across 8 categories and 7 departments

### Visualization
- Interactive pivot table with drag-and-drop fields
- Column charts for regional and departmental performance
- Color-coded status and variance indicators
- Responsive dashboard with draggable and resizable panels

### Export & Integration
- Excel and PDF export for pivot tables and data grids
- Column chooser for custom view configuration
- Ready for external API integration

### UI/UX
- Bootstrap 5 responsive design
- Collapsible navigation menu
- Excel-style filtering in data grids
- Professional financial dashboard aesthetic

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-financial-dashboard-syncfusion.git
cd blazor-financial-dashboard-syncfusion
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
